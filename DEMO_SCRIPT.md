# AgriSathi — Round 3 live demo script

## Opening (30 seconds)
"AgriSathi is a paddy-focused farm decision and risk management workspace. It helps a farmer organise field zones, record observations, review weather context, prioritise inspections and keep a traceable record of actions."

## Workflow (4–5 minutes)
1. Dashboard: identify sample data as illustrative.
2. Field zones: create a new plot, enter crop/area and initial moisture.
3. Field intelligence: show transparent HIGH/CHECK/MODERATE/LOW reason.
4. Reading entry: add a new reading and show the dashboard refresh.
5. Weather: fetch forecast for the farm coordinates; identify Open-Meteo and timestamp.
6. Irrigation review: select the field and rainfall context; explain limitations.
7. Reports: capture a photo or voice note and save it with a written observation.
8. Tasks: add an inspection task, mark it complete.
9. History/export: show audit events and download JSON.

## AI branch (only if provider is configured)
Upload a clear paddy image. Explain that the system returns possible visual observations, not a definitive diagnosis. Ask judges to note uncertainty and expert-review guidance.

## Closing (30 seconds)
"The prototype demonstrates a complete software workflow. Weather is live third-party context; field values are farmer-entered unless explicitly imported; AI only runs when a real provider is configured. No live 5G or hardware sensor deployment is claimed."
